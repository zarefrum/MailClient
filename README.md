# Консольный почтовый клиент на C#

Финальная практика по дисциплине «Основы проектирования баз данных».

**Стек:** Visual Studio, C# (.NET Framework 4.7.2), PostgreSQL, пакет Npgsql 4.1.9.

## Что умеет

- Регистрация (логин уникальный — повтор ловится по коду ошибки `23505`)
- Вход по логину и паролю
- Отправка письма другому пользователю
- Входящие — один запрос с `JOIN` (без проблемы N+1), непрочитанные помечены `*`
- Отправленные — через представление (VIEW) `message_list`
- Чтение письма — получателю письмо отмечается прочитанным
- Все запросы — только с параметрами (`@u`, `@p`), без склейки строк → нет SQL-инъекций

## База данных

Две таблицы: `users` и `messages`. Письмо ссылается на двух пользователей —
отправителя и получателя (внешние ключи `REFERENCES users(id)`).
Плюс VIEW `message_list` и индексы по `recipient_id` и `sender_id`.
Весь SQL — в файле [`database.sql`](database.sql).

## Как запустить

1. В pgAdmin создать базу `mail_client`, открыть на ней Query Tool и выполнить `database.sql`.
2. Открыть `MailClient.sln` в Visual Studio.
3. В `Program.cs` в строке `ConnString` указать свой пароль от PostgreSQL.
4. Нажать F5 (NuGet сам скачает Npgsql).

## Переход на MySQL

От конкретной БД зависят ровно два места — `NewConnection()` и `IsDuplicate()`,
плюс строка подключения. Варианты для MySQL оставлены в коде комментариями.
